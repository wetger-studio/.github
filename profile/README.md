## What we are building

| Project | What it is | Status |
| --- | --- | --- |
| **[Wetger OS](https://wetger.com/wetger-os)** | Open source Kubernetes control panel: clusters, CI/CD, container registry, domains, deployments, logs and metrics, in one self-hosted application. | Available |
| **[Tradya](https://wetger.com/tradya)** | SaaS running autonomous AI trading agents as isolated sessions. One model, one strategy, one risk budget each, with deterministic risk limits and a kill switch outside the model. Paper trading first. | Coming soon |
| **Next tool** | In design. Announced when it is real. | Soon |

## How we work

- **Open source first.** Code should be inspectable. What can be public, is.
- **Whole stack, one team.** We design, build and operate every product ourselves, from the cluster to the pixel.
- **Products we use daily.** Each product runs on the previous one, which keeps them honest.
- **Few things, done well.** One tool, one product at a time.
