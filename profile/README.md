## How we work

| | |
| --- | --- |
| **Open source first** | Code should be inspectable. What can be public, is. |
| **Whole stack, one team** | We design, build and operate every product ourselves, from the cluster to the pixel. |
| **Products we use daily** | Everything we ship is something we needed first. We are the first users of each release. |
| **Few things, done well** | One tool, one product at a time. We would rather finish something than start three. |
